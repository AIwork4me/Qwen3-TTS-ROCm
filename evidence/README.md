# Evidence

Verbatim records of the validation runs behind the numbers quoted in the
[README](../README.md) and [`docs/benchmarks.md`](../docs/benchmarks.md).
Everything here was produced on the recorded validation host
(**AMD Ryzen AI Max+ PRO 395 / Radeon 8060S, `gfx1151`, ROCm 7.14.0,
kernel 6.17.0-1032-oem, Python 3.12**) on 2026-08-27 unless noted. Files are
machine-generated command transcripts unless marked otherwise; they are
append-only records, not hand-edited reports.

Reproduce any of them with the commands in the `cmd:` header lines inside
each file, or follow [docs/benchmarks.md](../docs/benchmarks.md) and
[`tests/`](../tests/).
